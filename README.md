# 🚀 Featured Projects

### 🤖 AgentCal

**AI-powered calendar assistant** built around **AI agents, MCP, and Google Calendar**.

Allows users to interact with their calendar using **natural language**, while the agentic workflow translates user requests into calendar operations.

**Tech:** `Next.js` `TypeScript` `MCP` `Google Calendar API` `AI Agents`

---

### 🚗 GearHub

AI-powered **vehicle marketplace and inventory platform** built with **Next.js, TypeScript, Prisma, PostgreSQL, Supabase, and Gemini AI**.

Features AI-assisted vehicle information extraction, authentication, role-based access, image uploads, validation, and dealership-oriented inventory workflows.

**Tech:** `Next.js` `TypeScript` `Prisma` `PostgreSQL` `Supabase` `Gemini AI`

---

### 💻 CodeCrate

Real-time **multi-language code snippet manager** with a VS Code-like coding experience.

Includes Monaco Editor, authentication, multi-language support, user dashboards, and subscription management.

**Tech:** `Next.js` `TypeScript` `Monaco Editor` `Convex` `Clerk` `LemonSqueezy`

---

### 🌦️ Weatherly

Modern **real-time weather application** with location-aware weather information, forecasts, city search, search history, and favorites.

**Tech:** `React` `TypeScript` `Tailwind CSS` `Shadcn UI` `TanStack Query` `Recharts`
